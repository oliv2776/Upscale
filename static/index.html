DÉSACTIVÉ
Utiliser Ollama (facultatif)
Adresse joignable depuis le conteneur Uscale.
Les modèles sont chargés depuis /api/tags.
Intégration facultative, désactivée par défaut.

Si Ollama tourne directement sur le NAS, son API doit être accessible depuis Docker. Sur une installation Linux native, Ollama écoute souvent uniquement sur localhost : configure OLLAMA_HOST=0.0.0.0 puis redémarre Ollama, ou indique une adresse IP/port déjà accessible. Ne publie pas cette API sur Internet.
