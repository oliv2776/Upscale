07 / MODÈLES IA

Modèles personnalisés

Installe des modèles de la communauté depuis OpenModelDB en collant simplement leur lien : Upscale les télécharge, les convertit pour ta carte graphique et vérifie qu'ils fonctionnent.

MOTEUR NCNN
NOMFACTEURTUILESTAILLE
Page d'un modèle sur openmodeldb.info, ou lien direct vers un fichier .pth, .safetensors, .onnx ou .zip.
Importer un fichier depuis cet ordinateur
Un .pth, .safetensors, .onnx ou .zip — ou la paire .param + .bin (ncnn).

Choisis de préférence un modèle ×2 (360p → 720p) : beaucoup plus rapide qu'un ×4. Architectures recommandées : SPAN, Compact, ESRGAN. Les très lourdes (DAT, HAT, ATD...) sont refusées ou trop lentes. La première conversion d'un .pth installe le convertisseur (environ 1 Go, une seule fois). Teste chaque modèle dans l'Aperçu avant de l'utiliser, et respecte sa licence.

OPTIONNEL / ASSISTANT IA

Connexion Ollama

Avec un modèle de vision (llava, qwen2.5vl, gemma3…), le modèle IA « Automatique » choisit entre animation et prise de vue réelle.

DÉSACTIVÉ
Utiliser Ollama (facultatif)
Adresse joignable depuis le conteneur Upscale.
Les modèles sont chargés depuis /api/tags.
Intégration facultative, désactivée par défaut.

Si Ollama tourne directement sur le NAS, son API doit être accessible depuis Docker. Sur une installation Linux native, Ollama écoute souvent uniquement sur localhost : configure OLLAMA_HOST=0.0.0.0 puis redémarre Ollama, ou indique une adresse IP/port déjà accessible. Ne publie pas cette API sur Internet.
